# TypeScript & Tooling Config

Provenance: kensei-2 tsconfig/eslint.config.js/package.json; sentinals
tsconfig.

## tsconfig

- Extend `astro/tsconfigs/strict`. Never downgrade strictness.
- `jsx: preserve` + `jsxImportSource: solid-js` when Solid islands are used.
- Path alias `@/* → src/*` via baseUrl+paths (kensei).
- Include `.astro/types.d.ts` (generated by `astro sync`).

## Scripts (package.json)

```json
{
  "build": "astro build",
  "typecheck": "astro check",
  "lint": "eslint .",
  "format": "prettier .",
  "format:check": "prettier . --check"
}
```

kensei-2 is the reference set. sentinals ships build+typecheck only — adding
lint/format there is cheap and recommended at next touch.

## ESLint

Flat config (`eslint.config.js`) with typescript-eslint +
eslint-plugin-astro; `@typescript-eslint/no-explicit-any: warn`. Generated or
verbatim-copied files may be excluded with a stated reason
(kensei excludes content.config.ts as a verbatim copy).

## Prettier

prettier + prettier-plugin-astro. Format-on-save locally; `format:check` in
verification. Never reformat whole files inside content-fix commits (diff
hygiene — core definition-of-done step 6).
